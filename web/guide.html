◈ 表达训练室

返回训练网站

每天 45–60 分钟，把表达真正说出来。

第一次使用：先做这三步

  1. 进入「五天进度总览」，把开始日期设为你正式学习的第一天，新卡上限先设为 17。
  2. 进入「今日学习」，先尝试 5 张卡，熟悉回忆、揭晓和自评流程。
  3. 进入「口语练习」，回答一道 Part 1。先回答再展开参考，不追求一开始就完美。

每天的顺序

  1. 复习 10 分钟：先处理到期和不熟的表达，能快速说出一个自己的句子才算会用。
  2. 新卡 15 分钟：看中文，先口述英文，再点「显示答案」。用原创例句检查搭配，然后改成自己的经历。
  3. 真实题输出 15–25 分钟：Part 1 每题约 30 秒；Day 3 起加入 Part 2 的 1–2 分钟回答；Day 4 起加入 Part 3。
  4. 素材扫描与复盘 5–10 分钟：按计划浏览原讲义话题，勾选扫描清单。记下一个明天要再用的表达，并导出备份。

四个自评选项怎么选

选项判断依据
完全不会看中文说不出来，或只能看答案照读。
想起但不熟需要想很久、反复改口，或搭配还不确定。
可以使用不看答案，能在一个完整句子里准确用出。
自然脱口而出几乎不需要检索，并且放进自己的回答也自然。

搭配用错时勾选「这次搭配用错了」。系统采用自评，不会自动理解或评分你的英语。连续成功并跨至少两个日期，才计为跨日稳定。

口语练习怎么做

  1. 先看题目，选择是否显示表达提示。每次只挑真正合适的 1–2 个，不必全部使用。
  2. 点击「开始 / 继续」，直接说。可以录音，也可以只写一句复盘。
  3. 说完再打开「回答后查看参考与复盘」，检查是否回应问题、搭配是否正确、是否有具体细节。
  4. 勾选自己实际使用的表达；录音结束后点击「保存这次练习」。到「错词与复习记录」回听。
  5. 同一题再答一次时点「随机换题」或重新选择题目开始新尝试；同一次练习重复保存会更新该记录。

Part 2 的中文提纲只是例子，应替换为自己的经历；四项英文题卡要点都要回应。Part 3 可按「观点 → 原因 → 例子 → 适用范围」展开。

五天各练什么

  • Day 1：诊断基础句块，先准确用出来。
  • Day 2：Part 1 日常话题，把同一表达用到不同题目。
  • Day 3：Part 2 故事，每次只记故事要点，不背整篇。
  • Day 4：Part 3 观点、原因、影响与比较。
  • Day 5：不增加自动新卡；复习困难项，Part 1、2、3 混合模拟。

默认前四天每天 17 个，共 68 个核心表达。若耗时太长，可下调上限；宁可少学一些但能主动输出。B 级作为备用，C 级用于辨错，不作为背诵目标。

给外教课带什么

选 2–3 个今天刚练过的表达，在真实对话中尝试使用。请老师关注是否自然、搭配是否正确；课后把纠正内容写进对应卡片的笔记。

每天结束前备份一次

在「我的表达词库」或「五天进度总览」点击「完整备份（含录音）」，保存 JSON 文件。换设备时在相应页面选择「恢复 JSON 备份」。恢复会替换该浏览器已有记录，先备份旧数据。

GitHub 只托管网站内容，不保存你的个人进度。不同浏览器、不同设备不会自动同步；不要用无痕模式长期学习，也不要在未备份前清理网站数据。本网页 JSON 与原 Python 版本 SQLite 备份不能直接互换。
